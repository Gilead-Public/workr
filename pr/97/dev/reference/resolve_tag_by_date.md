# Resolve a tag by date when no releases exist

Resolve a tag by date when no releases exist

## Usage

``` r
resolve_tag_by_date(org, repo, date)
```

## Arguments

- org:

  Character. GitHub organization.

- repo:

  Character. Repository name.

- date:

  Date. Find latest tag on or before this date.

## Value

Character. The resolved tag name.
